# Milleo Designer · serviços e valores

Versão local de homologação do catálogo da Milleo Designer. A página é estática, pensada primeiro para celular e não depende de build ou backend.

## Abrir localmente

A partir desta pasta, inicie o servidor local incluído no projeto:

```powershell
node server.mjs
```

Depois, abra `http://localhost:4173`.

Também é possível abrir `dist/index.html` diretamente, mas um servidor local mantém o comportamento mais próximo de uma publicação real.

## Conteúdo incluído

- Fotos dos serviços em `dist/images/`.
- Valores retirados da tabela Milleo Designer e valores de cílios informados na conversa.
- Atalhos de agendamento com mensagens pré-preenchidas para o WhatsApp `+55 42 9971-9385`.
- Perfil do Instagram `@milleo_designer`.

Os botões de agendamento abrem uma conversa no WhatsApp. A pessoa ainda revisa e envia a mensagem pelo próprio aplicativo.
